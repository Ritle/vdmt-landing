# Лендинг «МедиаШОУ+»

Адаптивная одностраничная страница каталога материалов для ВидеоМОНТАЖа. В проекте только HTML, CSS, JavaScript и локальные изображения: сборка, серверное приложение и установка зависимостей для публикации не нужны.

Макет: [Figma](https://www.figma.com/design/xUerflKJsw1O1eE0nqX7iD/?node-id=0-1).

## Быстрый просмотр

Откройте `index.html` в браузере. Для проверки через локальный HTTP-сервер перейдите в папку проекта и, если установлен Python, выполните:

```bash
python -m http.server 8082
```

На некоторых системах команда Python называется `python3` или `py`. Затем откройте `http://localhost:8082/`. Порт 8082 нужен только для локального просмотра; на хостинге используется адрес сайта.

## Что уже работает

- Навигация по разделам и мобильное меню. Меню закрывается при выборе ссылки, по Escape и при переходе к широкой версии страницы.
- Темы подборок: три темы показывают готовые карточки; для тем без изображения выводится карточка со свободным местом под графику. Повторное нажатие на активную тему возвращает общий список.
- Семь тем блока «Видео по шаблону»: каждая выбирает соответствующий файл `video-preview-1.png` … `video-preview-7.png`. Сейчас это **изображения**, воспроизведения видео на странице нет.
- FAQ: одновременно раскрывается не более одного ответа; закрытые ответы скрыты и недоступны для фокуса.
- Плавное появление секций при прокрутке. При системной настройке уменьшения движения анимация отключается.

## Изменение страницы

- Тексты, цена, метаданные и якорные ссылки находятся в `index.html`. Согласуйте коммерческие условия перед их изменением.
- Цвета и семейства шрифтов заданы в начале `styles.css`. Используются Open Sans, Montserrat и Lora через Google Fonts: для их загрузки браузеру нужен доступ к этому сервису.
- Связь семи тем с файлами превью задана объектом `templatePreviewAssets` в `script.js`. Если имена файлов сохраняются, код менять не требуется.
- Атрибут `data-asset-slot` помечает место графики, но **не загружает файл автоматически**. Как подключать и заменять изображения, описано в [assets/README.md](assets/README.md).
- При изменении CSS или JavaScript увеличьте номера `?v=` у подключений `styles.css` и `script.js` в `index.html`, чтобы браузер обновил кэш.

## Публикация

Разместите `index.html`, `styles.css`, `script.js` и всю папку `assets/` в одной директории статического хостинга, сохранив имена файлов и относительные пути. Папка `docs/` нужна для передачи и сопровождения, но странице для работы не требуется. После загрузки проверьте главную страницу, изображения, шрифты и переключение тем на широком и узком экране.

Покупка пока не подключена: кнопка в тарифе отключена, а остальные кнопки «Купить» ведут к тарифному блоку. Перечень решений и проверок перед запуском — в [документе передачи](docs/HANDOFF.md).
