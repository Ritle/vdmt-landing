# vdmt-landing

Статический лендинг МедиаШОУ+, реализованный по макету Figma на чистых HTML, CSS и JavaScript.

Графика, нарисованная в прежней вёрстке вместо файлов из Figma, убрана. Под изображения и иконки оставлены пустые места с атрибутом `data-asset-slot`; их перечень находится в [assets/README.md](assets/README.md). Переданные пользователем файлы будут подключены отдельно.

## Структура

- `index.html` — семантическая разметка лендинга.
- `styles.css` — адаптивные стили, типографика и декоративные элементы.
- `script.js` — мобильное меню, FAQ-аккордеон, переключение тематических табов и плавная навигация.

## Локальный запуск

Можно открыть `index.html` напрямую в браузере или запустить любой статический HTTP-сервер, например:

```bash
python -m http.server 8080
```

После этого откройте `http://localhost:8080`.

## Технологии

Vanilla HTML / CSS / JavaScript, без сборщика и внешних JS-зависимостей.
