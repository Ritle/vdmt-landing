# Hero images

В hero-блоке теперь три независимые карточки.

Положите сюда свои изображения с именами:

- `hero-newyear.jpg` — Новый год
- `hero-wedding.jpg` — Свадьба
- `hero-birthday.jpg` — День рождения

Рекомендуемый размер исходника: около **520×380 px** или больше, с соотношением сторон примерно **1.37:1**.

Карточки используют `background-size: cover`, поэтому изображение автоматически обрезается под область 260×190 px.

Если нужны PNG/WebP или другие имена файлов, поменяйте путь в `index.html`:

```html
style="--card-image: url('assets/hero-newyear.jpg');"
```

Подпись, эмодзи, бейдж NEW, наклон и позиционирование карточки находятся отдельно от изображения и редактируются независимо.
