# Изображения и графика

Все пути к изображениям относительны папки проекта. Сохраняйте имена файлов при замене: тогда связи в разметке и переключателе превью останутся рабочими. Изображения с другими именами потребуют обновления `src` в `index.html` или карты `templatePreviewAssets` в `script.js`.

| Блок страницы | Используемые файлы |
| --- | --- |
| Первый экран | `catalog-1.png` — Новый год; `catalog-2.png` — свадьба; `catalog-3.png` — день рождения; `hero-decor.svg` — декоративные точки на широком экране. |
| Категории редактора | `feature-1.png` — стикеры; `feature-3.png` — рамки; `feature-2.png` — шаблоны; `feature-4.png` — футажи. |
| Подборки | `gift-2.png` — день рождения; `gift-1.png` — свадьба; `gift-3.png` — Новый год. |
| Видео по шаблону | `video-preview-1.png` … `video-preview-7.png`, по порядку кнопок. |
| Сценарии использования | `content-1.png` … `content-4.png`, по порядку карточек. |
| Для кого | `audience-visual.png`. |
| Подвал | `LOGO.png`. |

`hero-newyear.png`, `hero-wedding.png` и `hero-birthday.png` хранятся в папке, но текущая страница их не использует. Логотип в шапке и часть небольших иконок вставлены как SVG непосредственно в `index.html`. На телефоне вместо большого `hero-decor.svg` точки рисуются CSS, чтобы распределяться по высоте первого экрана.

## Семь превью

| Кнопка | Файл |
| --- | --- |
| С днём рождения | `video-preview-1.png` |
| Юбилей | `video-preview-2.png` |
| Свадьба | `video-preview-3.png` |
| Выпускной | `video-preview-4.png` |
| Семейный альбом | `video-preview-5.png` |
| Новый год | `video-preview-6.png` |
| Видео-подарок | `video-preview-7.png` |

Контейнер превью имеет размер 560 × 412 CSS px на широком экране, изображение заполняет его через `object-fit: cover`. Файлы 2–5 сейчас имеют размер 270 × 160 px: они увеличиваются и частично обрезаются по краям. Файлы 6 и 7 сейчас побайтово совпадают с файлом 1, поэтому при выборе этих тем изображение выглядит одинаково. Это состояние переданных файлов, а не ошибка переключателя. Если нужны разные тематические кадры, замените соответствующие PNG, сохранив имена; предпочтительно подготовить изображения под пропорцию 560:412.

Если выбранный PNG не загрузится, переключатель показывает `video-preview-1.png` как запасное изображение. Проверяйте новые файлы после публикации, чтобы ошибка имени не осталась незаметной.

## Темы подборок

Готовые изображения есть для дня рождения, свадьбы и Нового года. Для Дня Победы, выпускного, последнего звонка, юбилея, Дня матери, путешествий, каникул, хобби и отпуска переключатель показывает карточку с пустым местом под изображение. `data-asset-slot` в разметке лишь обозначает место: добавление файла в папку само по себе не вставит его на страницу. Чтобы заполнить карточку, добавьте в `index.html` изображение для темы или поручите подключение разработчику.
